# 🚀 Quick Test - Form Builder

## Start Testing in 3 Steps

### 1. Start Server
```bash
cd example
npm run dev
```

### 2. Open Browser
Go to: **http://localhost:3000/form-builder**

Or click the "🎨 Open Form Builder" button on the main page.

### 3. Try It Out

#### Builder Tab 🎨
1. **Drag** a "Text" input from left panel to canvas
2. **Click** on it to select
3. **Edit** properties in right panel (name, label, etc.)
4. **Add** more fields (Phone, Rating, Password)

#### Preview Tab 👁️ (NEW!)
1. **Switch** to Preview tab
2. **See** your form rendered in real-time
3. **Fill** out the form
4. **Submit** to see the captured data
5. **View** the JSON configuration

#### Export/Import
1. **Export** as JSON using toolbar button
2. **Clear** the form
3. **Import** the JSON back
