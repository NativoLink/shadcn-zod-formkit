# AGENTS

## Purpose
This repository contains a React library for building dynamic forms using `React`, `zod`, `react-hook-form`, `Tailwind`, and `shadcn` UI patterns. It also includes a Next.js `example/` app for integration and manual testing.

## What to know first
- Root package: `package.json` defines the library build, lint, and test commands.
- Example app: `example/package.json` is a separate Next.js workspace package that consumes the local library via `file:..`.
- Source code: `src/` contains the published library entrypoints and component/hook implementation.
- Docs: `docs/` contains development guides, quick start, and testing instructions.

## Primary commands
Use the root scripts unless working only in `example/`.

- `npm run build` - compile CSS and generate `dist/` artifacts for the library
- `npm run dev` - build the library in watch mode
- `npm run example:dev` - start the Next.js example app
- `npm run build:css` - build Tailwind CSS output
- `npm run lint` - run ESLint across the repo
- `npm test` - run Vitest tests
- `npm run test:ui` - run Vitest in interactive mode

From the `example/` folder, use:
- `npm run dev`
- `npm run build`
- `npm run start`
- `npm run lint`

## Key files and conventions
- `src/index.ts` exports the public library API
- `src/components/`, `src/hooks/`, `src/lib/` contain implementation and utilities
- `package.json` exports: `./hooks`, `./utils`, `./validation`, `./theme`
- CSS build uses `tailwindcss` v4 and output is written to `dist/tailwind.css`
- The example app uses React 19 / Next 16 and loads the local package for integration verification

## When editing code
- Preserve the library’s public API shape and exported `InputTypes` constants
- Prefer changes in `src/` and keep `dist/` generated by `npm run build`
- Use `example/` to validate rendering and interactive behavior
- Keep docs up-to-date by linking to `README.md` and `docs/` when adding features
